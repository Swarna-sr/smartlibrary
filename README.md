Smart Library 

Smart Library is an Android-based digital library application developed using Kotlin in Android Studio. The application allows users to search books online, save favorites, write reviews, follow users, chat, and share books through an interactive and user-friendly platform.

Features :

Search books using Google Books API
View detailed book information
Save favorite books
AI-based book recommendations
Add community reviews
Follow other users
Chat functionality
Share books with friends
Firebase Realtime Database integration
Offline storage using Room Database

Technologies Used :

Kotlin
Android Studio
Firebase Realtime Database
Room Persistence Library
Google Books API
Retrofit
Gson Converter
Picasso
RecyclerView
Kotlin Coroutines
Project Architecture

The project consists of:

UI Layer
API Layer
Local Database Layer
Firebase Cloud Integration
Screenshots 📱


Installation :
Clone the repository
git clone https://github.com/Swarna-sr/smartlibrary.git
Open in Android Studio
Add your Google Books API key in local.properties
GOOGLE_BOOKS_API_KEY=YOUR_API_KEY
Sync Gradle and Run the project
